# nRF5 SDK v17.1.0

This repository contains the **Nordic Semiconductor nRF5 Software Development Kit (SDK) v17.1.0**.

The nRF5 SDK enables Bluetooth Low Energy, ANT, and 2.4 GHz proprietary product development with Nordic Semiconductor's advanced nRF5 Series System on Chip (SoC) devices.
